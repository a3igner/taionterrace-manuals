HIS-PF Push-fit Under Counter Water Filter System (M12 Series)

Under Counter Water Filter · Kitchen sink

HIS-PF / M12 (BTU2501)

Made-in-Britain stainless steel under-sink filter system with a Biotect Ultra BTU2501 cartridge and a dedicated chrome drinking-water tap.

Quick reference — do this first

  • Flush the cartridge before first use. Run the full conditioning cycle in the instructions — it takes a few minutes and removes carbon dust.
  • Tubing must fit 3/8" push-fit with the stated tolerance — check the dimensions table before cutting.
  • An isolation valve and non-return valve are required upstream of the filter (UK legal requirement).
  • Install the user tap as described — it is the only outlet for filtered water.
  • Never use the filtered tap for hot water, and do not connect it to a boiling tap.
  • Replace the cartridge on schedule — the filter is for cold or room-temperature water only.
